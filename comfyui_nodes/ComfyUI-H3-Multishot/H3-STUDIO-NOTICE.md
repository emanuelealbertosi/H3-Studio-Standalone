# H3 Studio node pack

Questa cartella è uno snapshot distribuibile di
[ComfyUI-H3-Multishot](https://github.com/jlucasmcrell/ComfyUI-H3-Multishot)
alla base commit `1cf37633d9c77305f56769bb5ee172916ed21390`, con le estensioni
sviluppate per H3 Studio:

- autoprompter AIO e parser/validator;
- reference e motion memory;
- timestamp interni;
- router delle sei modalità H3;
- prompt skill locale e relativi asset;
- salvataggio delle continuazioni come segmenti autonomi.

Il file `LICENSE` conserva la licenza MIT del progetto di origine. Non
modificare direttamente questa copia dall'interfaccia ComfyUI: le modifiche
vanno mantenute qui e reinstallate con `INSTALL_COMFY_DEPENDENCIES.bat`.
